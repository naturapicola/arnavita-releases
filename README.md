## 🛠️ Com instal·lar l'APK al mòbil:
1. Descarrega el fitxer .apk mecant l'enllaç superior des del teu navegador mòbil.
2. Un cop descarregat, obre la notificació o el fitxer des del gestor de descàrregues.
3. Si el teu telèfon t'avisa de *"Fonts desconegudes"*, activa l'opció *"Permetre des d'aquesta font"* per completar la instal·lació.
4. L'aplicació s'instal·larà i podràs iniciar sessió amb el teu compte d'apicultor o amb Google.

A partir de la versió **v1.6.2**, el sistema d'actualització OTA d'Android compta amb el FileProvider segur configurat i et permet actualitzar amb un sol clic directament des de dins del mòbil per a totes les properes versions.
